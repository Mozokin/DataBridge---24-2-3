# Подготовка к защите

## Короткий сценарий

1. Открыть решение в Visual Studio и показать структуру модулей.
2. Показать configs/schema.json: required, type, unique, regex, диапазон и маппинг.
3. Открыть input.csv (20 записей) и выполнить convert из README.
4. Показать консоль, output.json, errors.csv и report.html в браузере.
5. Выполнить stats для input.xlsx и validate для input.json или input.xml.
6. Показать фактический лог тестов results/tests.txt и презентацию.

## Ответы на контрольные вопросы

1. **Чтение форматов.** Все адаптеры реализуют IReader, возвращают DataSet с колонками и списком Record. Formats выбирает адаптер по расширению.
2. **Новый формат.** Реализовать IReader и IWriter, зарегистрировать в Formats. Остальные модули работают с общей моделью.
3. **Валидация.** Конфиг JSON десериализуется в Config и FieldRule. Validator проверяет обязательность, тип, границы, regex, длину, уникальность и возвращает две группы записей с причинами ошибок.
4. **Некорректные строки.** Отклоняются, сохраняются в errors.csv с исходными данными, номером и причиной. Корректные продолжают обработку, чтобы одна ошибка не блокировала остальные данные.
5. **Маппинг.** Converter выполняет операции по списку transformations, затем заменяет имена полей по словарю mapping. Совпадение выходных имён считается ошибкой.
6. **Границы.** Предусмотрены тесты 15/16 и 100/101, високосной даты, длины строки, пустых значений, повторов и CSV-кавычек. Показывать фактические результаты после запуска.
7. **Ошибки чтения.** Парсеры выбрасывают исключения, CLI перехватывает ожидаемые исключения, выводит понятное сообщение и код 1. Повреждённый документ не выдаётся за корректный.
8. **HTML-отчёт.** Статистика, таблица полей и нарушений. Для оператора, аналитика или учебного отдела; помогает исправить источник.
9. **Миллион строк.** Потоковое чтение, проверка и запись; ограниченные буферы, множество уникальных ключей с возможным выносом на диск. Сейчас данные хранятся в памяти.
10. **Следующая версия.** Потоковый режим, вложенные структуры, выбор листа Excel, расширение правил, графический интерфейс или пакетная обработка файлов.
