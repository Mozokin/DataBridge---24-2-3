# Руководство пользователя

## Установка

1. Установить .NET 8 SDK (не только Runtime). В Visual Studio Installer выбрать рабочую нагрузку .NET.
2. Распаковать архив полностью. Открыть DataBridge.sln или терминал в корне проекта.
3. Выполнить `dotnet build DataBridge.sln`. Сборка не требует внешних библиотек.
4. На Windows запустить `run_demo.cmd` либо выполнить команды из README.

## Команды

| Команда | Назначение | Обязательные параметры |
|---|---|---|
| convert FILE | Проверка и преобразование | --config FILE, --to csv/json/xml/xlsx |
| validate FILE | Проверка без выходного файла данных | --config FILE |
| stats FILE | Статистика | Нет; --config FILE для настроек CSV |
| --help | Справка | Нет |

Дополнительные параметры convert: --output FILE (по умолчанию output.формат), --report FILE, --errors FILE. Для validate: --report FILE, --errors FILE. Отчёт по умолчанию report.html, ошибки errors.csv в каталоге выходного файла или отчёта. Папки создаются автоматически; существующие выходные файлы перезаписываются; нельзя указывать входной файл или конфиг как выходной.

После сборки можно вызывать `dotnet DataBridge/bin/Debug/net8.0/databridge.dll --help` или приложение `databridge.exe` на Windows.

## Диагностика

0 — успешно; 1 — ошибка файла, конфигурации или параметров; 2 — записи с нарушениями (корректный результат и отчёты сохранены). Проверяйте имена полей, формат файла, JSON-конфигурацию, права доступа. Закройте Excel перед перезаписью открытого .xlsx.

В HTML указаны номера записей (без строки заголовка), поля и значения. Ошибки хранят исходные записи; исправьте источник и запустите проверку повторно. Отчёты могут содержать исходные персональные данные: не публикуйте их без необходимости.
