# DataBridge — конвертер и валидатор данных

Учебный проект КТ №3. Инструмент командной строки для проверки и преобразования табличных данных без базы данных.

## Возможности

- Автоматическое распознавание CSV, JSON, XML и XLSX по расширению; запись в каждый из этих форматов.
- CSV с заголовками/без заголовков, настраиваемый разделитель; кавычки и многострочные значения.
- JSON: массив плоских объектов. XML: корневой элемент, записи и простые поля. XLSX: первый лист, первая строка — заголовки; чтение общих/встроенных строк, чисел, логических значений и распространённых форматов дат.
- Проверки required, type (integer, float, string, date, boolean), min/max, regex, unique, длина.
- Переименование полей, trim, upper, lower, replace, timestamp_to_date.
- Некорректные записи не попадают в результат; они сохраняются в errors.csv. HTML-отчёт и статистика выводятся отдельно.

## Требования и быстрый запуск

.NET 8 SDK, Windows/Linux/macOS; Visual Studio 2022 17.8+ с рабочей нагрузкой «Разработка классических приложений .NET» (или любой редактор). Сторонние NuGet-пакеты не требуются.

Откройте DataBridge.sln или терминал в корне проекта (там, где расположен README). Для Windows можно дважды щёлкнуть `run_demo.cmd`: сборка, запуск тестов, демонстрация CSV → JSON, статистика XLSX и открытие отчёта.

```powershell
dotnet --version
dotnet build DataBridge.sln
dotnet run --project DataBridge.Tests --no-build
dotnet run --project DataBridge --no-build -- convert samples/input.csv --to json --config configs/schema.json --output samples/output.json
dotnet run --project DataBridge --no-build -- validate samples/input.json --config configs/schema.json --report results/json/report.html
dotnet run --project DataBridge --no-build -- stats samples/input.xlsx
```

Код завершения 2 — ожидаемый при наличии некорректных строк; выход и отчёты при этом сохраняются. Код 0 — нет ошибок, 1 — ошибка чтения/конфигурации/запуска. Для примера input.csv ожидается 20 записей, 10 успешных, 10 отклонённых, 12 нарушений. `samples/expected_output.json` — эталон ожидаемого вывода, а не результат выполненного запуска. Реальные `output.json`, `errors.csv`, `report.html` создаёт приложение.

## Структура

`DataBridge/` — приложение и модули; `DataBridge.Tests/` — автономный набор unit-тестов (без NuGet, запускается через dotnet run); `configs/` — конфигурации; `samples/` — примеры четырёх форматов; `DOCS/` — требования, архитектура, спецификация, инструкции и тестирование; `TEAM.md`, `CONTRIBUTIONS.md` — команда.

## Ограничения

Данные загружаются в память; вложенные JSON/XML не поддерживаются; Excel: один лист, без пересчёта формул (читаются сохранённые значения), стандартные .xlsx, не .xls. Метаданные оформления при преобразовании не сохраняются. В CSV/JSON/XML сохраняются данные, а не типы оформления. Некорректная структура файла останавливает обработку; нарушения правил отдельных записей приводят к их отклонению. Уникальность проверяется среди ранее принятых записей; необязательные пустые поля не проверяются дальше.
