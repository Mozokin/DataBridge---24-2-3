# Состав и распределение ролей

**Проект:** DataBridge, КТ №3 по дисциплине «Программная инженерия».  
**Исполнитель:** Мозокин Роман Вадимович, группа ИВТ-24-2.  
**Преподаватель:** Посягин А. Е.

По согласованию с преподавателем проект выполняется индивидуально. Все проектные роли совмещены одним исполнителем.

| Роль | Зона ответственности |
|---|---|
| Архитектор / интеграция | Архитектура, общая модель данных, интерфейсы, CLI |
| Разработчик чтения и записи | CSV, JSON, XML, XLSX |
| Разработчик валидации | Правила, обработка ошибок, трансформации |
| Разработчик отчётности | HTML-отчёт, errors.csv, статистика |
| QA / документатор | Тестирование, документация, демонстрация |

Ответственный за сборку, локальную проверку и представление проекта — Мозокин Роман Вадимович. При подготовке исходного кода и документации использована помощь ИИ.
